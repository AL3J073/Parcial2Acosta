# Sistema AutoPark - Proyecto de Parcial

## ¿Cómo ejecutar el proyecto?
1. Descomprimir este archivo ZIP en una carpeta.
2. Abrir una terminal o consola de comandos en esa carpeta.
3. Ejecutar el archivo principal con Python:
   ```bash
   python main.py
   ```
   *(Si usas Linux/Mac, puede que necesites usar `python3 main.py`)*

## Archivos incluidos:
- `main.py`: Punto de entrada de la aplicación y menú interactivo.
- `core.py`: Lógica de negocio (Cálculo recursivo de estacionamiento, validaciones, desafío de medianoche).
- `batch.py`: Procesamiento de movimientos por lote (lee JSON y genera CSV).
- `tarifas.json`: Configuración de costos base, provista en el enunciado.
- `movimientos.json`: Lote de operaciones de prueba, provisto en el enunciado.
